## Release v1.0.0

Title:
```
MapSingularity 1.0.0
```

Notes:
```
First public release.

- Random Workshop map roulette: "Best maps" (popular, well rated) or "Whole Workshop".
- Background download, mount and BSP asset precache; the portal opens when the map is ready.
- Arrival with health, armor, weapons and ammo kept.
- STC "Harrier" gun: LMB portal, RMB another map, R collapse; green CRT terminal with live status.
- Three portal styles: Classic violet rings, Fun rainbow tunnel, Minimal black hole.
- English, Ukrainian and Russian.

Assets:
- map_singularity.gma — the Workshop package (or subscribe on the Workshop).
- MapSingularity_HostLoadingScreen.zip — optional: shows the portal tunnel on the host's own loading
  screen. Unpack and double-click install.bat; uninstall.bat puts everything back.
```
Attach `release/map_singularity.gma` and `release/MapSingularity_HostLoadingScreen.zip` (keep the zip name — the Workshop description links to it).
