# Тоннель вместо экрана загрузки: инструкция

Во время прыжка через портал вместо экрана загрузки показывается гиперпространственный
тоннель со звёздами (`web/ms_tunnel.js`, анимация на canvas). Кто что видит:

| Кто | Что видит при прыжке | Что нужно сделать |
|---|---|---|
| Игроки, подключённые к вашему серверу | тоннель | раздел 1: выложить страницу и прописать `ms_loading_url` |
| То же, если раздел 1 не сделан | чёрный экран (`portal_void.png` из аддона) | ничего |
| Вы — хост (одиночная игра или listen-сервер) | стандартный экран GMod | раздел 2 (патч) или раздел 3 (выделенный сервер) |

Почему хосту отдельно: меню GMod показывает тому, кто сам хостит игру, только свою
страницу `garrysmod/html/loading.html` и не смотрит на `sv_loadingurl`. Из аддона это не
обойти, а в мастерскую нельзя положить ни `.html`, ни `.gif` — их нет в списке
разрешённых файлов GMA.

---

## 1. Тоннель для подключающихся игроков

1. Выложите два файла на любой хостинг статических страниц с https — они должны лежать
   рядом в одной папке:
   - `web/portal_loading.html`
   - `web/ms_tunnel.js`

   Бесплатно через GitHub Pages:
   1. Создайте публичный репозиторий, например `ms-loading`.
   2. Загрузите в корень оба файла (Add file → Upload files).
   3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
   4. Через минуту страница будет по адресу `https://<ваш-логин>.github.io/ms-loading/portal_loading.html`.
      Откройте его в браузере — должен лететь тоннель.

2. Пропишите адрес на сервере. Надёжнее всего — строкой в `garrysmod/cfg/server.cfg`:
   ```
   ms_loading_url "https://<ваш-логин>.github.io/ms-loading/portal_loading.html"
   ```
   Для проверки можно ввести то же самое в консоли сервера.

3. Проверка: `ms_status` → строка «экран загрузки при прыжке — …: экран из ms_loading_url
   для N сетевых клиентов». Подмена `sv_loadingurl` включается только когда есть подключённые по сети
   игроки, после их входа исходное значение возвращается.

У игрока с `cl_enable_loadingurl 0` любые серверные экраны загрузки отключены — он увидит
стандартный.

## 2. Тоннель для хоста: патч экрана загрузки (5 минут)

Подходит для одиночной игры и для хоста listen-сервера. Меняет файлы игры только на вашем
компьютере.

**Установка.** Закройте GMod и выполните из папки проекта `C:\Project-work\garry_roulette`:
```bash
powershell -ExecutionPolicy Bypass -File tools\host-tunnel-patch.ps1 install
```
Если игра стоит не в `C:\Program Files (x86)\Steam\...`, добавьте путь:
```bash
powershell -ExecutionPolicy Bypass -File tools\host-tunnel-patch.ps1 install -GarrysModDir "D:\SteamLibrary\steamapps\common\GarrysMod\garrysmod"
```

Скрипт копирует `ms_tunnel.js` в `garrysmod\html\`, сохраняет `loading.html.ms-backup` и
добавляет в `loading.html` одну строку перед `</body>`.

**Проверка.** Запустите игру, зайдите на карту и введите `ms_status` — должно быть
«патч тоннеля у хоста …: установлен». При прыжке в консоли появится
«экран загрузки хоста: тоннель (патч установлен)».

**Как это работает.** На время прыжка аддон дописывает в конец `hostname` невидимый символ
U+2063. Меню передаёт имя сервера странице загрузки, патч видит метку и включает тоннель.
Без метки страница показывается как обычно — обычные загрузки карт не меняются. Когда вы
прогрузились на новой карте, метка снимается.

**Удаление:**
```bash
powershell -ExecutionPolicy Bypass -File tools\host-tunnel-patch.ps1 uninstall
```
Состояние: тот же скрипт с `status`.

**Ограничения:**
- Обновление GMod или «Проверить целостность файлов» в Steam вернёт оригинальный
  `loading.html` — запустите `install` ещё раз.
- Маленькое окно прогресса в правом нижнем углу («Lua Started!», кнопка «Отмена») рисует не
  страница, а само меню — оно останется поверх тоннеля.
- В начале любой загрузки страница до 0,7 с остаётся чёрной, пока решает, показывать ли
  тоннель.

## 3. Тоннель для хоста без патча: локальный выделенный сервер

Вы запускаете сервер отдельной программой и заходите на него как обычный игрок — тогда
работает раздел 1, и для вас тоже. Минусы: несколько гигабайт на диске, игра и сервер
работают одновременно, а скачивать карты сервер сможет только по прямой ссылке
(`file_url`) — выбор рулетки будет меньше.

1. Скачайте SteamCMD с сайта Valve (`https://developer.valvesoftware.com/wiki/SteamCMD`),
   распакуйте, например, в `C:\steamcmd`.
2. Установите сервер GMod (app 4020):
   ```bash
   C:\steamcmd\steamcmd.exe +force_install_dir C:\gmodds +login anonymous +app_update 4020 validate +quit
   ```
3. Скопируйте папку аддона
   `C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\addons\map_singularity`
   в `C:\gmodds\garrysmod\addons\`. Нужные вам аддоны мастерской подключаются коллекцией:
   `+host_workshop_collection <id>` (нужен ключ Web API: `-authkey <ключ>`).
4. Пропишите `ms_loading_url` в `C:\gmodds\garrysmod\cfg\server.cfg` (раздел 1).
5. Запустите сервер:
   ```bash
   C:\gmodds\srcds.exe -console -game garrysmod +gamemode sandbox +map gm_construct +maxplayers 8
   ```
6. Зайдите на него из игры: консоль → `connect 127.0.0.1:27015`.
   Друзьям из интернета нужен открытый UDP-порт 27015.
