# ТЗ: 3D-модель КПП «Лунь» для Garry's Mod

**КПП «Лунь»** — Комплекс Просторового Переходу. Гравипушка, доведённая кулибиными:
три когтя-захвата со светящимся шаром между ними, катушки на стволе, генератор под белым
кожухом с окном, ствольная коробка с магазином-батареей, рукоять и складной приклад, экран
сверху. Референсы — концепт «ГП-04 «Прорив»» (вид сбоку/сверху/спереди/сзади).

Код уже готов к модели: как только в аддоне появятся оба файла ниже, пушка возьмёт их
вместо пистолета-затычки, а экран прибора переедет из угла HUD на экран модели.

## Текущий путь (2026-11-18): процедурная модель с текстурами

Модель в аддоне — `models/map_singularity/kpp_lun.mdl` + `materials/models/map_singularity/kpp_lun/`
(6 материалов, ~7,5 МБ). Собирается одной командой (меш → запекание в Blender → компиляция):

```bash
python tools/model/build_lun.py
```

`--no-bake` — без Blender, на плиточных материалах (как до запекания).

1. `kpp_lun_mesh.py` — меш (раздел 0), игровой QC (`$origin 0 0 0 -90`, точки `muzzle`,
   `screen`/`screen_br` — углы детали `screen_glass`, `generator`), OBJ+MTL с текстурами.
   Вызывает `kpp_lun_textures.py`: бесшовные TGA 512² (плитка — 8 юнитов кубической проекции:
   пластик со сколами и грязью, воронёный и потёртый металл с царапинами, медь, бакелит,
   жёлто-чёрные полосы, стекло, светящиеся ядро и шар), табличка «КПП-04 // ВИРІБ «ЛУНЬ»» /
   «НДІ ПРОЕКТУВАННЯ · ЗАВ. № 0417» (UV растянута на деталь, текст читается с обеих сторон)
   и `materials.json` — параметры VMT (phong с плоской картой нормалей, `$selfillum` у свечения).
2. `bake_lun.py` (Blender, Cycles): сварка вершин, умная развёртка в атлас, проходы цвет /
   параметры / кромки (Emission), AO, нормали скруглённых фасок (Bevel, DirectX) → `kpp_body.tga`
   2048² (цвет с AO, грязью и потёртостями) + `kpp_body_normal.tga` 1024² (блеск в альфе),
   `kpp_lun_body.smd`; QC и `materials.json` переключаются на него. Светящиеся материалы и
   табличка остаются со своими текстурами. В конце — рендеры `render_*.png` с запечёнными текстурами.
3. `compile_lun.py`: `vtex` → VTF, `studiomdl` → MDL с физикой, VMT из `materials.json`,
   копирование в аддон (материалы прошлой сборки удаляются). Инструменты — из `GarrysMod/bin`.
4. Посмотреть без игры: `render_lun.py` (без запекания) (Blender, EEVEE: три ракурса в `art/kpp_lun/render_*.png`)
   и `preview_viewmodel.py` (кадр от первого лица с текущей подгонкой).

Модель из Tripo — запасной путь (оплывшие формы): `build_lun_from_glb.py` → `art/kpp_lun_tripo/`,
затем `compile_lun.py --work art/kpp_lun_tripo`.

От первого лица «Лунь» рисуется от камеры вьюмодели (конвары `ms_lunk_vm_*`), рук пока нет;
вьюмодель-носитель — гравипушка с невидимым мешем. Доставание и отдача — процедурные.
В руках у других — от правой кисти (`ms_lunk_wm_*`). Ползунки: Q → «Утилиты» →
MapSingularity → «Подгонка Луня». При смене модели — поднять `TUNE_VERSION` в
`weapon_singularity.lua`: сохранённая подгонка старой модели сбросится к новым значениям.
Привязка к костям рук гравипушки не годится: аддоны мастерской подменяют `c_physcannon`.
Отдельная c_-модель с собственным ригом рук (разделы ниже) вернёт руки и анимации.

## 0. Базовый меш уже есть

`tools/model/kpp_lun_mesh.py` (Python + numpy, без Blender) процедурно собирает чистый
hard-surface меш по концепту — 43 детали, ~7,7 тыс. полигонов (98 % квадов), ~16 тыс.
треугольников, все детали замкнуты, без немногообразных и перевёрнутых рёбер. Кости и точки
крепления — по этому ТЗ, `studiomdl` из GMod собирает его без ошибок.

```bash
python tools/model/kpp_lun_mesh.py
```

Результат — `art/kpp_lun/`: `kpp_lun.obj` (импорт в Blender: Forward X, Up Z) как основа для
развёртки, текстур и рига рук; `kpp_lun_ref.smd` + `kpp_lun.qc` — игровая модель;
`preview.html` — 3D-просмотр в браузере (кнопка «Сетка» показывает топологию); `report.txt` —
проверка сетки. Размеры деталей — константы в начале `build()`.

## 2. Основа скелета

Возьмите `models/weapons/c_physcannon.mdl` из GMod (гравипушка) и декомпилируйте Crowbar'ом:
в ней уже есть скелет рук `ValveBiped` для c_-моделей и кости когтей. Замените меш на «Луня»,
кости рук не трогайте — иначе руки игрока не встанут на оружие.

## 3. Кости

| Кость | Что | Чем анимируется |
|---|---|---|
| `lun_root` | корень оружия | отдача |
| `lun_claw_1`, `lun_claw_2`, `lun_claw_3` | когти-захваты | раскрытие при выстреле, сжатие на R |
| `lun_generator` | ротор/катушка под кожухом | вращение в idle, разгон на ПКМ |
| `lun_screen` | экран сверху | крепление экрана |
| `lun_trigger` | спуск | выстрел |
| `lun_mag` | магазин-батарея | осмотр |

## 4. Точки крепления (`$attachment`)

| Имя | Где | Ориентация | Зачем |
|---|---|---|---|
| `muzzle` | центр шара между когтями | X — вперёд по стволу | начало луча выстрела |
| `screen` | **левый верхний угол** видимой части стекла | X — вправо вдоль стекла, Y — вверх вдоль стекла (в GMod `Right()` — вниз), Z — из экрана к игроку | код рисует экран через `cam.Start3D2D` |
| `screen_br` | **правый нижний угол** видимой части стекла | как у `screen` | из расстояния между углами код берёт размер и пропорции экрана |
| `generator` | центр окна генератора | любая | свечение плазмы (на будущее) |

Размер экрана берётся из `screen`/`screen_br` (без `screen_br` — ширина `SWEP.ScreenWidth` и
пропорции 2:1). Точки ставятся **на плоскость стекла** (на 0,03 юнита к игроку), а не на
выступ рамки, иначе экран повиснет в воздухе. Само стекло — тёмный материал без надписей:
текст, осциллограмму и статус рисует код.

В QC обязательно `$origin 0 0 0 -90`: иначе studiomdl повернёт модель на 90° и ствол уйдёт в +Y.

На мировой модели — те же `muzzle` и `screen`.

## 5. Анимации вьюмодели

| Sequence | Activity | Когда | Длительность |
|---|---|---|---|
| `idle` | `ACT_VM_IDLE` | всегда; генератор медленно крутится | цикл |
| `draw` | `ACT_VM_DRAW` | доставание (экран в это время 1,4 с «грузится») | ~1,0 с |
| `holster` | `ACT_VM_HOLSTER` | убрать | ~0,5 с |
| `fire` | `ACT_VM_PRIMARYATTACK` | ЛКМ: когти раскрываются и щёлкают, отдача | ≤ 0,8 с (перезарядка выстрела 0,8 с) |
| `reroll` | `ACT_VM_SECONDARYATTACK` | ПКМ: генератор разгоняется, искры в окне | ≤ 1,5 с |
| `collapse` | `ACT_VM_RELOAD` | R: когти сжимаются | ~0,8 с |
| `inspect` | `ACT_VM_FIDGET` | осмотр (на будущее) | любая |

## 6. Мировая модель

Скелет с `ValveBiped.Bip01_R_Hand` (как у `w_physics.mdl`), положение подогнать под хват
`physgun` — его код включает автоматически вместе с моделью. До 5 000 треугольников.

## 7. Материалы и маркировка

- Кожух — грязно-белый пластик со сколами; ствольная коробка — потёртый металл; рукоять и
  приклад — бакелит/дерево. Phong для металла.
- Окно генератора — `$selfillum 1` (или `$additive`) с анимированной плазмой
  (`AnimatedTexture`-прокси).
- Шар между когтями — отдельный материал со `$selfillum`, лучше спрайт-шейдер.
- Декали трафаретом на боковой части ствольной коробки: `КПП-04 // ВИРІБ «ЛУНЬ»`,
  жёлто-чёрные полосы, мелкая «паспортная» табличка `НДІ ПРОЕКТУВАННЯ`.

## 8. Бюджет и масштаб

- Вьюмодель — до 20 000 треугольников, текстуры 2048² (diffuse + normal + phong exponent).
- 1 юнит ≈ 1 дюйм. Длина в руках — около 40–45 юнитов, как у гравипушки: длиннее не влезет в
  кадр от первого лица.

## 9. Сборка

Blender + Blender Source Tools → SMD/DMX → studiomdl через Crowbar. Каркас QC (координаты
креплений подставить из сцены):

```
$modelname "map_singularity/c_kpp_lun.mdl"
$cdmaterials "models/map_singularity/kpp_lun/"
$body "body" "c_kpp_lun_ref.smd"
$surfaceprop "metal"

$attachment "muzzle"    "lun_root"      0 0 0 rotate 0 0 0
$attachment "screen"    "lun_screen"    0 0 0 rotate 0 0 0
$attachment "generator" "lun_generator" 0 0 0 rotate 0 0 0

$sequence "idle"     "anims/idle.smd"     loop fps 30 activity "ACT_VM_IDLE" 1
$sequence "draw"     "anims/draw.smd"          fps 30 activity "ACT_VM_DRAW" 1
$sequence "holster"  "anims/holster.smd"       fps 30 activity "ACT_VM_HOLSTER" 1
$sequence "fire"     "anims/fire.smd"          fps 30 activity "ACT_VM_PRIMARYATTACK" 1
$sequence "reroll"   "anims/reroll.smd"        fps 30 activity "ACT_VM_SECONDARYATTACK" 1
$sequence "collapse" "anims/collapse.smd"      fps 30 activity "ACT_VM_RELOAD" 1
$sequence "inspect"  "anims/inspect.smd"       fps 30 activity "ACT_VM_FIDGET" 1
```

Проверка в игре: положить файлы в `addons/map_singularity/`, перезапустить карту,
`ms_give_gun` — экран прибора должен оказаться на модели, а не в углу HUD.
